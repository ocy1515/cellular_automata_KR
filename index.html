셀룰러 오토마타 실험실

색상 조건, 주변 8칸 감지, 사용자 지정 색상, 여러 칸 이동을 조합해 개미의 규칙을 만들어 보세요.

1. 규칙 선택

자유 입력과 예제 중 하나를 골라 적용합니다. 지금 시뮬레이션에 쓰이는 쪽이 강조 표시됩니다. 한 줄에 규칙 하나를 작성하며, 조건이 여러 개 맞으면 위쪽 규칙 하나만 실행합니다.

2. 시뮬레이션 설정

시뮬레이션 화면

단계 0
개미 위치 50, 50
방향 ↑ 북
사용 상태 2

개미는 격자 중앙에서 시작합니다. 기본 경계 설정은 끊김이므로 가장자리에 도달하면 개미가 멈춥니다. 밝은 민트색 표식이 개미의 위치와 진행 방향입니다.

한 단계마다 개미는 현재 칸과 주변 8칸을 먼저 감지한 다음, 가장 먼저 일치한 규칙의 행동을 순서대로 실행합니다. 이동 도중에는 규칙을 재검사하지 않습니다. 저작권 표기는 소스 코드 하단을 참고하세요.

규칙 설명

1. 칸 조건 감지 (condition)

ant_cell_(location)=(color)
  • &를 사용하여 여러 조건을 동시에 작성할 수 있다.
  • 여러 규칙의 조건이 동시에 성립하면 먼저 작성된 규칙 하나만 실행한다.

2. 칸 위치 (location)

위치 번호는 화면 기준으로 고정된다.

[2][3][4]
[5][1][6]
[8][7][9]

3. 색상 지정 (color)

setcolor (sign)=(Hex code)
setcolor B=#0000FF
  • (sign): A-Z 중 하나의 상태 기호
  • (Hex code): #RRGGBB 형식의 16진수 색상 코드

4. 명령 (order)

(1) paint (color)
이동 명령이 완료된 후 개미가 위치한 칸을 지정한 상태로 변경한다.

(2) paint_prev (color)
마지막 이동 명령이 시작되기 전에 개미가 있던 칸을 지정한 상태로 변경한다.

(3) 기본 이동 명령

  • straight: 현재 시선 방향으로 한 칸 이동
  • right: 오른쪽으로 90도 회전한 후 한 칸 이동
  • left: 왼쪽으로 90도 회전한 후 한 칸 이동
  • flip: 180도 회전한 후 한 칸 이동

(4) 여러 칸 이동 명령
기본 이동 명령 뒤에 _n을 붙여 이동 거리를 지정한다. (예: straight_2, left_3)

(5) 여러 명령 연결
;를 사용하여 여러 명령을 순서대로 연결한다.

5. 규칙 작성 형식

(condition) -> (order)

6. 여러 칸 이동 및 명령 실행 시점

  • 여러 칸 이동 명령이 실행되는 동안 중간에 지나가는 칸에서는 규칙을 다시 검사하지 않는다.
  • 이동 명령이 완료된 도착 위치에서 다음 규칙을 검사한다.
  • 따라서 중간에 지나간 칸에서는 별도의 규칙이 실행되지 않는다.
  • 한 규칙의 이동 경로가 경계를 벗어나면 해당 규칙은 부분 실행되지 않고, 이동 및 색칠을 적용하지 않은 채 정지한다.

7. 예시

setcolor A=#FFFFFF
setcolor B=#202040
setcolor C=#00BFFF
setcolor D=#FF00AA
setcolor E=#FFD700

ant_cell_1=A & ant_cell_3=B -> right_2; paint_prev C
ant_cell_1=A & ant_cell_6=C -> left; paint_prev D
ant_cell_1=A & ant_cell_9=D -> flip; paint_prev E
ant_cell_1=A -> straight; paint_prev B

ant_cell_1=B & ant_cell_3=C -> left_2; paint E
ant_cell_1=B & ant_cell_5=D -> right; paint C
ant_cell_1=B -> straight; paint_prev A

ant_cell_1=C & ant_cell_7=E -> flip; paint_prev D
ant_cell_1=C & ant_cell_6=B -> right_2; paint A
ant_cell_1=C -> left; paint_prev E

ant_cell_1=D & ant_cell_2=C -> straight_2; paint_prev B
ant_cell_1=D & ant_cell_4=E -> right; paint A
ant_cell_1=D -> flip; paint_prev C

ant_cell_1=E & ant_cell_8=B -> left_2; paint_prev D
ant_cell_1=E & ant_cell_9=A -> straight; paint C
ant_cell_1=E -> right; paint_prev B

8. 배경 상태 (setbg)

setbg (sign)
setbg B
  • 격자의 모든 칸이 처음에 갖는 상태를 (sign)으로 정한다. 코드에서 한 번만 쓸 수 있고, 생략하면 A이다.
  • 배경 칸도 일반 칸과 똑같이 취급되므로, 그 상태의 규칙이 그대로 실행된다. 배경이 A이면 A 조건의 규칙이 발동한다.

9. 개미 시작 칸 색 (setstart)

setstart (sign)
setstart C
  • 개미가 처음 서 있는 칸의 상태를 (sign)으로 정한다. 코드에서 한 번만 쓸 수 있고, 생략하면 배경 상태와 같다.
